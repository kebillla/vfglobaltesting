# Лендинг «Вход в трейдинг» (VolFix)

Одностраничник RU/KZ для продажи входа в закрытую Telegram-группу по крипторынку.
Бонус к подписке — 2 недели VolFix.

## Стек

Статика: HTML + CSS + vanilla JS. Без сборки, без npm, без внешних библиотек и шрифтов.
Одна страница весит ~55 КБ (HTML+CSS+JS+SVG), грузится одним раундом запросов —
это критично, т.к. основной трафик мобильный и с рекламы.

Деплой: любой статический хостинг. Для Vercel — просто `vercel deploy` из корня
(папка `api/` подхватится как serverless-функции, когда их доделают).

```bash
python3 -m http.server 4321   # локальный просмотр: http://localhost:4321
```

### Кэш при обновлениях

CSS и JS подключены с версией: `styles.css?v=2`, `app.js?v=2` и т.д.
**После каждого деплоя поднимайте номер версии** (`?v=3`, `?v=4`...) в `index.html`
и `success.html` — иначе браузеры и CDN отдадут старые скрипты поверх нового HTML:
разметка обновится, а тексты и стили останутся прежними.

## Структура

```
index.html              лендинг (9 секций)
success.html            страница успеха после оплаты (выдача ссылки)
assets/css/styles.css   все стили
assets/js/config.js     ЦЕНА, ссылки, ID пикселей, тумблеры  <- правится чаще всего
assets/js/i18n.js       словари RU / KZ (154 ключа, зеркальные)
assets/js/app.js        i18n, UTM, квиз, форма, модалка, заглушка оплаты
assets/js/analytics.js  GTM / GA4 / Meta Pixel / TikTok Pixel + единый track()
assets/img/chart.svg    фоновая иллюстрация (свечи + объёмы)
api/lead.js             ЗАГЛУШКА: приём лида
api/payment-webhook.js  ЗАГЛУШКА: вебхук оплаты -> Telegram invite-ссылка
```

## Что настраивается без правки вёрстки

Всё в `assets/js/config.js`:

| Поле | Что делает |
|---|---|
| `price.amount / currency / period` | цена подставляется во все блоки (hero, тариф, sticky, форма) |
| `price.oldAmount` | зачёркнутая старая цена; `null` — не показывать |
| `volfixBonusWeeks` | «2 недели» во всех текстах обоих языков |
| `payment.provider / payUrl` | `stub` — демо-режим; иначе редирект на платёжку |
| `leads.endpoint` | куда POST-ить лид; пусто — лид падает в localStorage + консоль |
| `quizEnabled` | мини-квиз перед формой (сегментация лидов) |
| `seats.left / total` | честный urgency; `seats: null` — блок скрыт |
| `links.*` | Telegram, поддержка, оферта, политика |
| `analytics.*` | ID пикселей; пустой ID = скрипт вообще не грузится |
| `i18n.default` | язык по умолчанию |

## Языки

Переключатель в шапке. Приоритет: `?lang=kk` в ссылке → выбор пользователя
(localStorage) → язык браузера → `ru`. Параметр `?lang=` удобно вешать на
креативы под казахоязычную аудиторию.

RU и KZ полностью зеркальные — одинаковый порядок блоков и CTA.
**Казахский текст — смысловой перевод, его стоит вычитать носителю языка
перед запуском рекламы** (это продающий текст, не документация).

Добавить/поправить строку: `assets/js/i18n.js`, ключ есть в обоих словарях.
Подстановки в тексте: `{weeks}`, `{price}`, `{period}`, `{left}`, `{total}`.

## Аналитика и UTM

`assets/js/analytics.js` поднимает GTM / GA4 / Meta Pixel / TikTok Pixel — только
те, у которых в конфиге указан ID. Все события идут через одну точку `window.track()`:

| Событие | Когда |
|---|---|
| `ViewContent` | загрузка страницы |
| `InitiateCheckout` | клик по любому CTA (в параметрах — какой именно: hero/pricing/sticky/final) |
| `QuizStep` | ответ в квизе (опыт / бюджет) |
| `Lead` | форма отправлена |
| `Purchase` | оплата (пока заглушка, флаг `stub: true`) |
| `LangSwitch` | смена языка |

UTM-метки (`utm_*`, `fbclid`, `ttclid`, `gclid`) снимаются при первом заходе,
сохраняются в localStorage и уходят вместе с лидом — источник виден даже если
человек вернулся позже напрямую.

## Что сделано заглушкой (по ТЗ)

1. **Оплата.** Кнопка ведёт на экран-заглушку → `success.html`. Когда выберут
   эквайринг: `payment.provider` + `payment.payUrl` в конфиге, редирект уже написан
   в `app.js` (функция `bindForm`).
2. **Выдача Telegram-ссылки.** `success.html` показывает placeholder-ссылку.
   Сценарий выдачи расписан по шагам в `api/payment-webhook.js`:
   вебхук → `createChatInviteLink` (`member_limit: 1`, `expire_date`) → показать
   на странице успеха + продублировать на email и SMS.
3. **Хранение лидов.** Сейчас localStorage + консоль. Для MVP достаточно
   Google Sheets: поднять `api/lead.js`, указать `leads.endpoint = '/api/lead'`.
4. **Фото/видео эксперта** — плейсхолдер в блоке «Кто ведёт».
